# NeuroGolf 2026: оптимизация ONNX без компромиссов в корректности

Это очищенная и воспроизводимая версия моих наработок для соревнования
[The 2026 NeuroGolf Championship](https://www.kaggle.com/competitions/neurogolf-2026).
Итог: **7356.87 балла и 540-е место**.

Вместо одной модели участники создавали 400 отдельных ONNX-графов для задач на
визуальные преобразования. Каждый граф должен был точно реализовать правило
задачи на неизвестных входах. Среди корректных решений выше оценивался граф с
меньшей суммой памяти промежуточных тензоров и количества параметров.

Проект содержит:

- локальный расчёт стоимости и структурные проверки ONNX;
- точную валидацию примеров в двух режимах ONNX Runtime;
- безопасный gate для принятия только корректных и более дешёвых кандидатов;
- воспроизводимый пример компактного ONNX-графа;
- подробный разбор формата, пайплайна, рисков и полученных уроков.

Начать лучше с [основного README](README.md), затем перейти к
[описанию соревнования](docs/competition.md), [методологии](docs/methodology.md)
и [краткому введению в ONNX](docs/onnx-primer.md).

Исходные данные соревнования, бинарные сабмиты, выгрузки leaderboard и чужие
артефакты намеренно не публикуются. В репозитории нет ключей, персональных
путей и данных других участников.
